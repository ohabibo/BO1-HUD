# BO1-HUD

Fork of [5and5/BO1-HUD](https://github.com/5and5/BO1-HUD) with Moon's
PES suit and hacker tool pickup fixed (see [#1](https://github.com/ohabibo/BO1-HUD/issues/1)).

## Download

[Link](https://github.com/ohabibo/BO1-HUD/releases)

## General
* 90 FOV
* Fixed backwalk speed

## HUD
* Timer - starts once the player can move
* Zombie counter
* Health bar
* Drops - counts power-up drops
